Tutorials

  • ✎ᝰ.To apply CSS in cave, copy the link in the card of the style you like and paste it into the field under number 1(Cave CSS URL).
  • ✎ᝰ.To use the blocks in the cave, copy the HTML code and paste it into field number 2(Cave Description).
  • ✎ᝰ.To apply CSS to your branch, copy the link from the card for the style you want and paste it into the "description" field. The link is marked with the number 3 in the image.
  • ✎ᝰ.To use the blocks to your branch, copy the HTML code and paste it into the "description" field below the CSS link. The HTML is marked with the number 4 in the image.
